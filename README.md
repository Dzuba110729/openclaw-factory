# OpenClaw Factory — шаблон контент-фабрики

Команда из 9 ИИ-агентов на OpenClaw: каждый агент — отдельный Telegram-бот
со своей ролью, памятью и набором скиллов. Агенты передают друг другу задачи
(`sessions_send`) и собирают контент от брифа до публикации во ВКонтакте.

Это **чистый шаблон**: в нём нет ключей, памяти агентов, данных бренда и клиентов.
Всё, что зависит от проекта, вынесено в плейсхолдеры `{{…}}`.

## Агенты

| id | Роль | Что делает |
|---|---|---|
| `coordinator` | 🟡 Координатор | принимает задачу, раскладывает по агентам, следит за статусом |
| `marketer` | 📈 Маркетолог | аудитория, смыслы, контент-план, реклама |
| `copywriter` | 🟠 Копирайтер | тексты постов, заголовки, сценарии |
| `designer` | 🟣 Дизайнер | обложки, карусели, лендинги, AI-картинки и видео |
| `smm` | 📣 СММ | дирижёр пайплайна поста, публикация и комментарии ВК |
| `methodist` | 📚 Методист | мини-курсы: структура, сценарии HeyGen, описания |
| `seo` | 🔍 SEO-аудитор | аудиты сайтов, SEO-статьи |
| `tech` | 🟢 Технарь | обслуживание OpenClaw, скрипты, интеграции |
| `brain` | 🧠 Архивариус | общая память и база знаний команды |

## Структура

```
agents/<id>/
  AGENTS.md  SOUL.md  TOOLS.md      роль, правила, инструменты — гейтвей вживляет в промпт
  IDENTITY.md  USER.md  HEARTBEAT.md  BOOTSTRAP.md
  learning/   patterns / anti-patterns / corrections — агент копит сам
  memory/     дневная память агента (не коммитится)
  knowledge/  база знаний проекта (бренд, аудитория, тон)
  projects/   рабочие материалы по проектам (не коммитится)
agents/smm/scripts/   vk.js (API ВК, Long Poll), гейты комментариев и утреннего разбора
skills/               37 скиллов (копирайтинг, дизайн, видео, ВК, Telegram, память…)
  brand-kit/          ← заполнить первым: цвета, шрифты, тон бренда
config/openclaw.example.json   конфиг гейтвея: агенты, allowlist скиллов, боты, привязки
scripts/              проверка входа Claude, ротация логов, переиндексация памяти, замер промпта
launchd/              автозапуск гейтвея и гейтов на macOS
```

## Развёртывание под новый проект

1. Поставить OpenClaw и войти в Claude CLI (`claude /login`) — модели идут через OAuth подписки,
   без API-ключа.
2. Скопировать шаблон: `cp -R agents ~/openclaw-factory/agents`, `cp -R skills/* ~/.openclaw/skills/`,
   `cp scripts/*.sh ~/.openclaw/scripts/`.
3. Создать 9 ботов у [@BotFather](https://t.me/BotFather), токены вписать в конфиг.
4. Заменить плейсхолдеры (список ниже) во всех файлах, например:
   ```bash
   grep -rl '{{BRAND}}' ~/openclaw-factory ~/.openclaw/skills | xargs sed -i '' 's/{{BRAND}}/MyBrand/g'
   ```
5. Заполнить `skills/brand-kit/SKILL.md` и `agents/*/knowledge/` материалами бренда.
6. Конфиг: `config/openclaw.example.json` → `~/.openclaw/openclaw.json`.
7. Ключи — в `.env` агентов по образцу `.env.example` (никогда не в код и не в md).
8. launchd: убрать `.example`, положить в `~/Library/LaunchAgents/`, `launchctl bootstrap gui/$(id -u) <plist>`.
9. Проверка: `openclaw status`, затем `openclaw agent --agent smm` без `--deliver`.

## Плейсхолдеры

| Плейсхолдер | Что это |
|---|---|
| `{{HOME}}` | домашний каталог (`/Users/<you>`) |
| `{{OWNER_NAME}}`, `{{OWNER_TG_USERNAME}}`, `{{OWNER_TG_ID}}` | владелец: имя, ник и числовой ID в Telegram |
| `{{TIMEZONE}}`, `{{FORM_OF_ADDRESS}}` | часовой пояс; «На «Вы»» или «На «ты»» |
| `{{BRAND}}`, `{{BRAND_SITE}}`, `{{PROJECT_SLUG}}` | бренд, сайт, короткое имя проекта для путей |
| `{{PRODUCT}}`, `{{PRODUCT_SLUG}}` | основной продукт (для методиста) |
| `{{VK_GROUP_ID}}`, `{{VK_GROUP_SCREEN_NAME}}` | ID и короткое имя сообщества ВК |
| `{{TG_BOT_TOKEN_<ID>}}` | токены ботов, по одному на агента |
| `{{GATEWAY_TOKEN}}` | случайная строка: `openssl rand -hex 24` |
| `{{MISTRAL_API_KEY}}` | Mistral — эмбеддинги памяти и распознавание голосовых |
| `{{TMPDIR}}` | `echo $TMPDIR` |

## Что важно знать

- **Гейты вместо кронов.** `vk-gate.sh` и `smm-morning.sh` проверяют условие в шелле и будят модель
  только когда есть работа — на тишине это ноль токенов.
- **Публикация только после «да» владельца.** СММ не постит без явного согласия — это правило в его SOUL.
- **`skillsSnapshot`.** Живая сессия агента донашивает старый список скиллов; после правки
  allowlist в конфиге сессии нужно сбросить.
- **Под `claude-cli` не действуют** `contextPruning`, `compaction`, `thinkingDefault` — они оставлены
  в конфиге, но промпт они не меняют.
