# Рендер каруселей

## Запуск

```bash
node ~/.openclaw/skills/carousel/render/render.js slides.json ./out
```

На выходе — `slide-01.png`, `slide-02.png` и так далее в указанном каталоге.

Зависимостей нет. Скрипт использует установленный Google Chrome в headless-режиме. Если Chrome лежит нестандартно:

```bash
CHROME_BIN="/путь/к/chrome" node render.js slides.json ./out
```

Поддерживаются также Chromium и Microsoft Edge.

## Формат slides.json

```json
{
  "theme": {
    "bg": "#0f2419",
    "fg": "#ffffff",
    "accent": "#7cb342",
    "font": "-apple-system, Helvetica Neue, Arial, sans-serif",
    "size": [1080, 1350]
  },
  "slides": [
    { "kind": "cover", "title": "Заголовок", "subtitle": "Подзаголовок" },
    { "kind": "point", "num": 1, "title": "Мысль", "body": "Пояснение" },
    { "kind": "cta",   "title": "Что делать", "body": "Призыв" }
  ]
}
```

### Типы слайдов

| kind | Назначение | Поля |
|------|-----------|------|
| `cover` | Обложка, крупный шрифт, без счётчика | `title`, `subtitle` |
| `point` | Обычный слайд с номерным кружком | `title`, `body`, `num` |
| `cta` | Финальный, заголовок акцентным цветом | `title`, `body` |

Поле `num` необязательно — без него кружок не рисуется.

### Тема

Все поля `theme` необязательны, есть значения по умолчанию.

| Поле | Что задаёт | По умолчанию |
|------|-----------|--------------|
| `bg` | фон | `#0f2419` |
| `fg` | основной текст | `#ffffff` |
| `accent` | полоса слева, кружок, заголовок CTA | `#7cb342` |
| `font` | CSS-стек шрифтов | системный |
| `size` | `[ширина, высота]` в пикселях | `[1080, 1350]` |

Цвета бренда брать из `knowledge/brand/` воркспейса или скилла `brand-kit`, а не выдумывать.

## Форматы под площадки

| Площадка | Размер | Примечание |
|----------|--------|------------|
| Лента 4:5 | `[1080, 1350]` | основной формат, максимум площади в ленте |
| Квадрат 1:1 | `[1080, 1080]` | универсально, но мельче в ленте |
| Сторис 9:16 | `[1080, 1920]` | важное — в центральной трети |

## Шрифты

Скрипт рендерит системными шрифтами. Кириллица работает из коробки.

Фирменный шрифт подключается через `theme.font`, если он установлен в систему:

```json
"font": "'PT Sans', -apple-system, Arial, sans-serif"
```

Проверить, что шрифт есть: `fc-list | grep -i "имя"` или через «Шрифты» в macOS. Если шрифта нет, Chrome молча подставит запасной — сверяй результат глазами.

## Проверка результата

Всегда открывай отрендеренные PNG и смотри:

- [ ] Текст не вылез за края и не обрезался
- [ ] Длинные заголовки не переносятся уродливо
- [ ] Читается при уменьшении до размера превью в ленте
- [ ] Счётчик слайдов не перекрывает текст

Если текст не помещается — **сокращай текст**, а не уменьшай шрифт. Слайд с мелким шрифтом не читают.

## Отправка владельцу

```bash
mkdir -p /tmp/openclaw && cp ./out/slide-01.png /tmp/openclaw/ && \
openclaw message send --channel telegram --account smm --target {{OWNER_TG_ID}} \
  --media /tmp/openclaw/slide-01.png --message "Карусель, слайд 1"
```

По одной команде на файл. Отправлять из `/tmp/openclaw/` или `~/.openclaw/media/shared/` — другие пути заблокированы.
