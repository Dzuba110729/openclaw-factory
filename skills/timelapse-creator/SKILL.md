# Timelapse Creator — таймлапсы

Два разных сценария: ускорение готового видео и сборка ролика из отдельных кадров.

## Инструмент

`ffmpeg` установлен (9.0.1, `/opt/homebrew/bin/ffmpeg`). Проверка: `ffmpeg -version`.

## Ускорение готового видео

```bash
# в 10 раз быстрее (setpts = 1/скорость)
ffmpeg -i in.mp4 -vf "setpts=0.1*PTS" -an out.mp4

# в 30 раз
ffmpeg -i in.mp4 -vf "setpts=0.0333*PTS" -an out.mp4
```

Звук при ускорении обычно не нужен — `-an` его убирает.

## Сборка из кадров

Кадры именовать по порядку: `frame-001.png`, `frame-002.png`…

```bash
# 24 кадра в секунду
ffmpeg -framerate 24 -i frame-%03d.png -c:v libx264 -pix_fmt yuv420p out.mp4

# медленнее — 8 кадров в секунду
ffmpeg -framerate 8 -i frame-%03d.png -c:v libx264 -pix_fmt yuv420p out.mp4
```

`-pix_fmt yuv420p` обязателен, иначе видео не откроется на части устройств.

## Из съёмки по таймеру

```bash
# каждый 30-й кадр исходника
ffmpeg -i in.mp4 -vf "select='not(mod(n\,30))',setpts=N/24/TB" -an out.mp4
```

## Плавность

Резкий таймлапс из редких кадров дёргается. Сгладить:

```bash
# интерполяция до 60 fps
ffmpeg -i in.mp4 -vf "minterpolate=fps=60:mi_mode=mci" out.mp4
```

Считается долго. На простых сценах работает хорошо, на сложном движении даёт артефакты — смотреть результат.

## Анимация из сгенерированных изображений

Рабочая связка с генерацией:

1. Сгенерировать базовый кадр — скилл `nano-banana`
2. Сгенерировать варианты **с тем же референсом**, меняя в промпте одну деталь (время суток, положение объекта)
3. Собрать последовательность через ffmpeg
4. Либо сделать переход между двумя кадрами моделью — скилл `veo-video`, модель `veo-3.1-fast-fl`

Переход, сгенерированный моделью, плавнее, чем склейка двух картинок, но стоит денег. Для двух-трёх кадров дешевле ffmpeg с плавным кроссфейдом:

```bash
ffmpeg -i a.png -i b.png -filter_complex \
  "[0:v][1:v]xfade=transition=fade:duration=1:offset=2" out.mp4
```

## Параметры под задачу

| Задача | Частота кадров | Длина |
|--------|----------------|-------|
| Фон под текст | 24–30 fps | 5–10 с |
| Демонстрация процесса | 24 fps | 10–20 с |
| Заставка | 30 fps | 3–5 с |

## Проверка

- [ ] Нет дёрганья и мерцания
- [ ] Все кадры в одном разрешении — иначе ffmpeg ругнётся или обрежет
- [ ] Нумерация файлов без пропусков
- [ ] `-pix_fmt yuv420p` проставлен
- [ ] Открывается на телефоне

Пропуск в нумерации (`frame-001`, `frame-003`) обрывает сборку на первом отсутствующем файле — переименовать подряд.
