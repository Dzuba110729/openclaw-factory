# Антипаттерны — что вычищать перед публикацией

## Маркеры ИИ-текста

Читатель не сформулирует претензию, но почувствует неживой текст. Вычищай:

| Конструкция | Почему плохо | Замена |
|-------------|--------------|--------|
| «Это не просто X, это Y» | Шаблонное надувание | Сказать прямо, что это |
| «Давайте разберёмся» | Пустой разгон, ноль информации | Сразу разбираться |
| «В современном мире» | Мёртвое начало, годится к любому тексту | Конкретная ситуация |
| «Важно понимать, что» | Слово-паразит перед мыслью | Убрать, оставить мысль |
| «Ключевым аспектом является» | Канцелярит | «Главное —» |
| «Не только..., но и...» | Механическое расширение | Одно утверждение |
| Три прилагательных подряд | Признак заполнения объёма | Одно точное |
| «Итак», «Таким образом», «В заключение» | Швы конструкции наружу | Убрать |
| Абзацы одинаковой длины | Машинный ритм | Рвать ритм намеренно |
| Риторический вопрос через абзац | Имитация диалога | Максимум один на пост |

## Пустые усилители

Слова, которые ничего не добавляют. Удали — смысл не изменится:

очень, достаточно, довольно, весьма, крайне, поистине, настоящий, реальный,
буквально, просто, действительно, определённо, безусловно, несомненно

Исключение — когда слово несёт точный смысл: «достаточно 2 капсул» (здесь это мера, а не усилитель).

## Мёртвые клише

уютный уголок, индивидуальный подход, широкий спектр, высокое качество,
команда профессионалов, инновационное решение, на страже вашего здоровья,
секрет прост, мало кто знает, врачи скрывают

## Опасные формулировки

В тематике здоровья и БАД — юридический риск, не только стилистический:

| ❌ Нельзя | ✅ Можно |
|-----------|---------|
| лечит, вылечит, излечивает | способствует, поддерживает, помогает при |
| гарантируем результат | доказанная эффективность, клинические испытания |
| похудей за N дней | поддержка нормального веса, метаболизм |
| заменяет лекарства | дополняет рацион |
| безопасно для всех | есть противопоказания, нужна консультация |

## Давление

Максимум 3 коммерческих слова на текст. Под запретом:

срочно, успей, только сегодня, последний шанс, не упусти, осталось N мест,
все уже купили, ты всё ещё не

Спокойный призыв работает дольше. Давление даёт всплеск и выжигает доверие.

## Проверка перед отправкой

1. Поиском по тексту прогнать список пустых усилителей
2. Прочитать вслух — где споткнулся, там переписать
3. Закрыть текст и пересказать своими словами. Не получилось — читатель тоже не сможет
4. Проверить каждое утверждение о продукте: чем подтверждается?
5. Если текст датирован («до сентября осталось две недели») — проверить, не протух ли
