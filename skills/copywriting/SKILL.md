# Copywriting — удержание внимания

Метод «скользкой горки» Джозефа Шугермана: задача каждого предложения — заставить прочитать следующее. Первое предложение существует только ради второго.

## Сначала — голос бренда

Перед написанием прочитай в своём воркспейсе, если файлы есть:

- `knowledge/brand/voice-style.md` — тон, запрещённые слова, форматы
- `knowledge/brand/audience.md` — кто читает
- `knowledge/brand/selling-map.md` — смыслы и аргументы

Эти файлы **важнее** любого правила ниже. Правила универсальны, бренд конкретен.

## Чек-лист сильного текста

**Обязательное:**

1. **Одна цель на текст.** Ответь себе: что текст даёт читателю и что даёт нам. Два ответа — значит текст один.
2. **Сокращай в 1,5–2 раза.** Первый черновик всегда длиннее нужного.
3. **Пиши подряд, редактируй отдельно.** Не правь в процессе — собьёшь поток.
4. **Занимай позицию.** «Можно посмотреть по-разному» — это не текст, это уклонение.
5. **Максимум 3 коммерческих слова на текст.** Без «успей», «только сегодня», «не упусти».
6. **Текст про читателя, не про нас.** Каждый абзац проверяй вопросом «а ему это зачем?».
7. **Конкретика вместо абстракций.** Цифры, сроки, названия, механизмы. Мозг отфильтровывает общее.
8. **Без канцелярита.** «Осуществляем поддержку» → «поддерживаем».
9. **Визуальные образы.** Читатель должен увидеть, а не понять.
10. **Разбивай сложные предложения.** Одна мысль — одно предложение.
11. **Проговори вслух.** Споткнулся при чтении — споткнётся и читатель.
12. **Лови двусмысленности.** Что может быть понято неправильно — будет понято неправильно.

**Усиливающее:**

13. **Пиши так, чтобы пересказали.** Один запоминающийся факт ценнее трёх абзацев описания.
14. **Говори на языке задачи читателя,** а не на языке продукта.
15. **Без обмана и давления.** Обещание, которое нельзя подтвердить, — не аргумент.

## Запрещённые конструкции

Это маркеры машинного текста, вычищай их безжалостно:

- «Это не про X, это про Y» — шаблонное противопоставление
- «Давайте разберёмся» / «Итак, поехали» — пустой разгон
- «В современном мире» / «В наше время» — мёртвое начало
- «Не просто X, а целый Y» — надувание
- Три прилагательных подряд через запятую
- Абзацы-близнецы одинаковой длины — текст должен дышать неровно

## Порядок работы

1. Прочитать бренд-файлы воркспейса
2. Сформулировать цель поста одной строкой
3. Заголовок и первую строку — через скилл `headlines`
4. Черновик подряд, без правок
5. Сократить в 1,5–2 раза
6. Прогнать через `references/anti-patterns.md`
7. Финальная вычитка через скилл `editing`
