# Nano Banana — генерация изображений

Движок: Gemini Image через LaoZhang API. Ключ — **твой собственный**, оплата идёт с баланса LaoZhang и ни от каких подписок не зависит.

## Ключ

```
~/.openclaw/agents/designer/.env
  LAOZHANG_API_KEY=sk-...
  LAOZHANG_BASE_URL=https://api.laozhang.ai
```

Ключ в чат не печатать. Проверить баланс:

```bash
source ~/.openclaw/agents/designer/.env
curl -s "https://api.laozhang.ai/v1/user/balance" -H "Authorization: Bearer $LAOZHANG_API_KEY"
```

## Генерация

```bash
python3 ~/.openclaw/skills/nano-banana/scripts/generate.py \
  --prompt "промпт" --ratio 16:9 --size 4K --out cover.png
```

Параметры и работа с референсами — `references/api.md`.

**Каждый вызов стоит денег.** Перед генерацией серии — сначала один кадр, посмотреть, потом остальное.

## Главный принцип промпта

**Специфика побеждает неопределённость.** Описание сцены работает, список ключевых слов — нет.

| ❌ Список слов | ✅ Описание сцены |
|----------------|-------------------|
| «женщина, портрет, реалистично, 4k» | «Женщина сорока лет у окна кухни, утренний свет сбоку, спокойное лицо, взгляд в сторону, мягкие тени» |

## Структура промпта

```
1. Что в кадре   — субъект и действие
2. Окружение     — где, время суток
3. Свет          — источник, направление, мягкость
4. Композиция    — план, ракурс, куда смотрит субъект
5. Стиль         — фотография / иллюстрация / рендер
6. Детали        — материалы, фактуры, цвета
```

Библиотека готовых формулировок — скилл `nano-banana-pro-prompts`.

## Место под текст

Если на изображении будет заголовок — заложи под него пустую зону **в промпте**:

```
...левая треть кадра свободна, равномерный тёмный фон без деталей
```

Иначе текст ляжет на лицо или на важную деталь, и картинку придётся перегенерировать.

## Бренд

Перед генерацией — цвета, стиль и ограничения из `knowledge/brand/` воркспейса или скилла `brand-kit`. Сгенерированная в чужой палитре картинка бесполезна, сколько бы она ни стоила.

## Соотношения сторон

| Задача | ratio | Примечание |
|--------|-------|-----------|
| Обложка поста | `16:9` | универсально |
| Лента | `4:5` | больше площади в ленте |
| Квадрат | `1:1` | карточки |
| Сторис, вертикаль | `9:16` | важное в центральной трети |

## Проверка результата

Смотреть глазами **всегда**. Типовые провалы генерации:

- [ ] Руки и пальцы
- [ ] Текст на изображении — обычно нечитаемая имитация букв, лучше накладывать текст отдельно
- [ ] Симметрия лица, глаза
- [ ] Логика предметов: количество, пропорции, тени
- [ ] Есть ли свободное место под заголовок
- [ ] Соответствие палитре бренда

## Что дешевле не генерировать

- Текст на картинке — накладывать отдельно, скилл `carousel` или графический редактор
- Точные схемы и графики — рисовать кодом
- Логотип — брать готовый файл
