# Структура поста

## Базовые 6 блоков

Универсальный каркас для поста в Telegram или ВК:

1. **Хук** (1–2 строки) — ломает прокрутку. Через скилл `headlines`
2. **Проблема** (2–4 строки) — узнаваемая ситуация читателя, без нагнетания
3. **Механизм** (основной объём) — почему так происходит, как это устроено
4. **Решение** (3–5 строк) — что с этим делать
5. **Доказательство** (1–3 строки) — исследование, документ, цифра, опыт
6. **Призыв** (1 строка) — одно конкретное действие, спокойно

Блоки 3 и 4 — сердце поста. Если их можно выкинуть без потери смысла, поста нет.

## Форматы под задачу

### Научный пост
Объясняем механизм. Цепочка «причина → процесс → следствие → вывод».
Термин вводим и сразу объясняем простыми словами. Не больше двух терминов на пост.

```
Хук → знакомый симптом → что происходит внутри (цепочка) →
почему привычные решения не работают → что работает → почему
```

### Развлекательный пост
Узнаваемая сцена из жизни аудитории. Юмор без панибратства.
Польза всё равно обязательна — иначе это просто шум в ленте.

```
Сцена → узнавание («да, это про меня») → неожиданный разворот →
мягкий вывод по теме
```

### Продуктовый пост
Строго: состав → механизм → для кого → как принимать.
Без обещаний результата, без «лечит». Только то, что подтверждено документами.

```
Задача читателя → какой компонент за неё отвечает →
как работает → кому подходит → схема приёма → где купить
```

### Пост-ответ на возражение
Возражение озвучиваем сами, честно и полностью. Слабую версию возражения
разбирать бессмысленно — читатель заметит подмену.

```
Возражение целиком → «и это справедливо, потому что...» →
что здесь упускают → факт/документ → спокойный вывод
```

## Объёмы

| Площадка | Комфортный объём | Потолок |
|----------|------------------|---------|
| Telegram | 900–1600 знаков | 3000 |
| ВКонтакте | 800–1400 знаков | 2500 |
| Подпись к карусели | 400–800 знаков | 1200 |

Длиннее потолка — режь на два поста. Telegram обрезает длинный текст кнопкой
«Показать полностью», и обрыв почти всегда попадает в неудачное место.

## Оформление

- Абзац — максимум 4 строки, дальше пустая строка
- Эмодзи — как маркеры списка, не как украшение. Максимум 3–5 на пост
- Жирным — один-два ключевых тезиса, не больше. Всё жирное = ничего не жирное
- Списки — когда перечисление, а не когда лень строить абзац
- Ссылку — в конце, отдельной строкой
