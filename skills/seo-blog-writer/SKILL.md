# SEO Blog Writer — статьи для сайта

Статья должна отвечать на вопрос читателя лучше, чем первые пять результатов выдачи. Оптимизация — это следствие полезности, а не замена ей.

## Сначала — голос бренда

Если в воркспейсе есть `knowledge/brand/voice-style.md` — прочитай. Тон, обращение и запрещённые формулировки важнее любого SEO-приёма.

## Порядок работы

1. **Запрос.** Один главный запрос на статью. Два главных — две статьи
2. **Интент.** Чего человек хочет: понять, выбрать, купить, сделать. От этого зависит всё остальное
3. **Выдача.** Посмотреть, что уже в топе. Если все дают одно и то же — вот пробел, который надо закрыть
4. **План.** Заголовки H2 как список вопросов читателя
5. **Текст.** По плану, через скиллы `copywriting` и `editing`
6. **Оптимизация.** Заголовок, описание, подзаголовки, ссылки
7. **Проверка** по чек-листу

## Интент и формат

| Интент | Что ищет | Формат статьи |
|--------|----------|---------------|
| Информационный | «что такое», «почему» | Разбор с механизмом |
| Навигационный | название бренда, продукта | Страница продукта, не статья |
| Коммерческий | «какой выбрать», «сравнение» | Сравнение с критериями |
| Транзакционный | «купить», «цена» | Карточка, не статья |

Писать статью под транзакционный запрос — потраченное время.

## Ключевые запросы

- **Главный** — в заголовке H1, в первом абзаце, в title
- **Дополнительные** (3–7) — в подзаголовках H2 естественно
- **Плотность** не считать. Считать, читается ли текст вслух без спотыканий

Переспам вида «купить метабиотик метабиотик цена метабиотика» — это минус позиции и минус доверие.

## Объём

| Тип | Объём |
|-----|-------|
| Разбор понятия | 4 000–7 000 знаков |
| Сравнение | 6 000–10 000 знаков |
| Инструкция | 3 000–5 000 знаков |

Ориентир — объём топа выдачи по запросу. Но дописывать «воду» до объёма конкурента бессмысленно: длина без пользы не ранжируется.

## Тематика здоровья — особые требования

Поисковые системы строже относятся к текстам про здоровье. Обязательно:

- Автор с указанием квалификации или ссылка на экспертизу бренда
- Ссылки на исследования и документы
- Дата публикации и дата обновления
- Дисклеймер: не заменяет консультацию специалиста
- Никаких «лечит», «гарантируем», «избавит от»

Без этого статья не выйдет в топ по конкурентному запросу, сколько её ни оптимизируй.

## Перед публикацией

- [ ] Заголовок H1 один, содержит главный запрос
- [ ] Title до 60 знаков, description до 155
- [ ] Подзаголовки H2/H3 выстроены логично, не пропускают уровни
- [ ] Первый абзац отвечает на запрос сразу, без разгона
- [ ] Каждое утверждение о продукте подкреплено
- [ ] Внутренние ссылки на 2–4 свои страницы
- [ ] Картинки с alt-текстом
- [ ] Читается вслух без спотыканий
