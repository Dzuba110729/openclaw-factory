# Veo Video — генерация видео

Движок Veo через LaoZhang API, тот же ключ, что у `nano-banana`. Оплата с баланса LaoZhang.

**Видео дороже изображений в разы.** Не запускать серию, пока не одобрен один ролик.

## Генерация

```bash
python3 ~/.openclaw/skills/veo-video/scripts/veo.py \
  --prompt "промпт" --model veo-3.1-fast --out clip.mp4
```

Процесс асинхронный: задача ставится, статус опрашивается, готовое скачивается. Скрипт делает это сам. Детали API — `references/api.md`.

## Модели

| Модель | Когда |
|--------|-------|
| `veo-3.1-fast` | черновики, проверка идеи — дешевле и быстрее |
| `veo-3.1` | финал |
| `veo-3.1-fast-fl` | переход между двумя заданными кадрами |

Порядок работы: идея → `fast` → правки → финал на полной модели.

## Промпт для видео

К структуре промпта изображения добавляется **движение**:

```
1. Что в кадре     — субъект и обстановка
2. Действие        — что происходит, одно движение
3. Камера          — статична / медленный наезд / проезд / облёт
4. Свет и палитра
5. Темп            — плавно, медленно, без резких смен
```

Пример:

```
Капля падает в стакан воды, крупный план, камера статична,
мягкий боковой свет, медленное расхождение кругов на поверхности,
холодная палитра, плавный темп
```

## Правила

- **Одно действие на ролик.** Два действия — модель смешает их в кашу
- **Камера простая.** Сложные движения дают артефакты
- **Без текста в кадре** — генерируется нечитаемая имитация букв. Текст накладывать на монтаже, скилл `video-editor`
- **Без лиц крупным планом** в длинных планах: мимика плывёт
- **5–8 секунд** — оптимальная длина. Длиннее растёт риск артефактов

## Оживление изображения

Сгенерированную картинку можно анимировать: передать её как референс и описать **только движение**.

```bash
python3 scripts/veo.py --prompt "медленный наезд камеры, лёгкое движение воздуха" \
  --ref cover.png --out cover-anim.mp4
```

Описывать заново, что на картинке, не нужно — модель это видит.

## Проверка результата

- [ ] Нет плывущих рук, лиц, предметов
- [ ] Движение выглядит физично
- [ ] Нет мерцания между кадрами
- [ ] Ролик работает без звука
- [ ] Первая секунда уже интересна

Артефакты чаще всего в конце ролика — смотреть до конца.

## Тематика здоровья

Те же ограничения, что для изображений: не показывать приём продукта как лечение, никаких «до/после», без имитации медицинских специалистов.
