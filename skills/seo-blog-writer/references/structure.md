# Структура SEO-статьи

## Каркас

```
H1            — главный запрос, один на страницу
Лид (2–4 стр) — ответ на запрос сразу, без разгона
H2 — вопрос 1 — самый частый вопрос по теме
H2 — вопрос 2
  H3 — уточнение
H2 — вопрос 3
H2 — Итог     — краткие ответы списком
Источники     — ссылки на исследования и документы
```

## Лид

Первые 2–4 строки решают, останется читатель или вернётся в выдачу.

- Прямой ответ на запрос **в первом же абзаце**
- Без «в современном мире», «многие задаются вопросом»
- Обещание, что будет дальше — одной строкой

Ошибка: разогреваться три абзаца перед ответом. Человек пришёл за ответом, а не за статьёй.

## Подзаголовки

Формулировать как **вопросы читателя**, а не как разделы документа.

| ❌ | ✅ |
|----|----|
| Общая информация | Что такое метабиотик |
| Механизм действия | Как он работает в кишечнике |
| Особенности применения | Кому подходит, а кому нет |
| Заключение | Что запомнить |

Подзаголовки-вопросы попадают в блоки быстрых ответов поисковика.

## Разметка

| Элемент | Правило |
|---------|---------|
| H1 | ровно один, содержит главный запрос |
| H2 | 4–8 штук, каждый — отдельный вопрос |
| H3 | только внутри H2, не пропускать уровень |
| Списки | когда перечисление, а не для разбавления |
| Таблицы | для сравнений — хорошо ранжируются |
| Выделение | 1–2 тезиса на экран |

## Метаданные

```
title:       до 60 знаков, главный запрос ближе к началу
description: до 155 знаков, обещание пользы + запрос
h1:          может отличаться от title, пишется для человека
url:         короткий, латиницей, через дефис
```

## Картинки

- `alt` описывает, что изображено, с упоминанием темы — но не набор ключей
- Имя файла осмысленное: `metabiotik-mehanizm.jpg`, не `IMG_2841.jpg`
- Сжимать: тяжёлая страница теряет позиции
- Первая картинка — не шире экрана, не отодвигает текст вниз

## Внутренние ссылки

2–4 ссылки на свои материалы, из текста, естественным якорем.

- Якорь описывает, что по ссылке, а не «читайте здесь»
- Ссылки на продукт — не больше двух на статью, иначе читается как реклама

## Источники

Для тематики здоровья — обязательный блок в конце:

- Исследования с названием и годом
- Декларации, документы производителя
- Ссылки рабочие, проверенные

## Технический чек-лист

- [ ] URL короткий и читаемый
- [ ] Title и description заполнены и не дублируют друг друга
- [ ] H1 один
- [ ] Иерархия заголовков не пропускает уровни
- [ ] Все картинки с alt
- [ ] Дата публикации проставлена
- [ ] Внутренние ссылки не битые
- [ ] Страница открывается быстро
- [ ] Читаемо с телефона
