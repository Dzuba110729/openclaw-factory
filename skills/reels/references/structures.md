# Структуры коротких роликов

## 1. Разрушение мифа

```
0–3    «[Распространённое убеждение] — это не так»
3–10   Почему в это верят
10–35  Как на самом деле: механизм
35–50  Что делать вместо
50–60  Призыв
```

Сильный формат для научного контента. Требует реального доказательства — иначе кликбейт.

## 2. Три причины

```
0–3    «Три причины, почему [проблема]»
3–8    Обозначить проблему
8–20   Причина 1
20–32  Причина 2
32–45  Причина 3 — самая неочевидная, её анонсировать в хуке
45–60  Вывод и призыв
```

Самую интересную причину ставить последней и обещать её в начале — это держит до конца.

## 3. Ответ на вопрос подписчика

```
0–3    Зачитать вопрос дословно
3–8    «Отвечаю честно»
8–45   Ответ по существу, с механизмом
45–60  Приглашение задавать вопросы
```

Самый дешёвый в производстве и хорошо работает на доверие. Вопросы брать из комментариев ВК и Telegram.

## 4. Что я перестал делать

```
0–3    «Я перестал [привычное действие]»
3–10   Что делал раньше и почему
10–35  Что понял
35–50  Что делаю теперь
50–60  Призыв
```

Личный формат, требует настоящего опыта. Выдуманная история считывается.

## 5. Разбор состава / этикетки

```
0–3    Предмет в кадре: «Смотрим, что тут написано»
3–15   Первый компонент — что делает
15–30  Второй
30–45  На что смотреть при выборе
45–60  Призыв
```

Предметный формат, хорошо удерживает: в кадре есть что рассматривать.

## 6. До / после по процессу

```
0–3    Результат сразу, без объяснения
3–10   «Как получилось»
10–45  Шаги
45–60  Вывод
```

Показывать результат первым кадром — единственный способ удержать на процессе.

## Как выбрать

| Задача | Формат |
|--------|--------|
| Показать экспертизу | Разрушение мифа, Разбор состава |
| Собрать охват | Три причины |
| Укрепить доверие | Ответ на вопрос, Что я перестал делать |
| Объяснить продукт | Разбор состава |

## Серия

Три ролика по одной теме работают лучше трёх разрозненных. В конце каждого — что будет в следующем.

Не растягивать одну мысль на серию: каждый ролик должен быть ценен сам по себе, иначе первый же пропуск обрывает цепочку.
