# Промпты для генерации изображений

Справочник формулировок. Генерация — скилл `nano-banana`.

## Принцип

Модель понимает **описание сцены**, а не список тегов. Одно связное предложение с конкретикой работает лучше десяти ключевых слов через запятую.

Порядок в промпте: субъект → окружение → свет → композиция → стиль → детали.

## Свет

| Нужно | Формулировка |
|-------|--------------|
| Мягкий портретный | «мягкий рассеянный свет из большого окна слева, тени едва обозначены» |
| Утро | «низкое утреннее солнце, длинные мягкие тени, тёплый оттенок» |
| Студийный | «студийный свет: основной источник сверху-слева, заполняющий справа, фон отделён» |
| Контровой | «источник света за объектом, светящийся контур по краю, лицо в полутени» |
| Ровный предметный | «равномерный бестеневой свет, как в лайтбоксе» |
| Драматичный | «единственный жёсткий источник сбоку, глубокие тени, высокий контраст» |

Свет — самый сильный рычаг. Изменение одной этой части меняет кадр сильнее, чем перечисление стилей.

## Композиция

| Нужно | Формулировка |
|-------|--------------|
| Портрет | «поясной план, лицо в трёх четвертях, взгляд мимо камеры» |
| Крупно | «макро, объект занимает большую часть кадра, малая глубина резкости» |
| Общий | «общий план, объект в правой трети, много воздуха слева» |
| Сверху | «вид строго сверху, предметы разложены на плоскости» |
| Место под текст | «левая треть кадра — равномерный фон без деталей» |

Формулировка про свободное место обязательна, если сверху ляжет заголовок.

## Стили

| Стиль | Формулировка |
|-------|--------------|
| Документальное фото | «репортажная фотография, естественный свет, без постановки» |
| Предметная съёмка | «предметная фотография на однотонном фоне, мягкие тени, высокая детализация материала» |
| Минимализм | «минималистичная композиция, много пустого пространства, два-три цвета» |
| Научная иллюстрация | «чистая векторная иллюстрация, плоские цвета, без градиентов» |
| Кинокадр | «кинематографический кадр, широкий формат, приглушённая палитра» |

## Фактуры и материалы

Называть материал конкретно: «матовое стекло», «шероховатый крафт-картон», «полированная нержавеющая сталь», «лён с видимым плетением», «капли конденсата на холодном стекле».

Общее «качественный материал» не даёт ничего.

## Персонаж в серии

Чтобы человек оставался тем же от кадра к кадру:

1. Сгенерировать базовый кадр, отобрать лучший
2. Дальше **всегда** передавать его через `--ref`
3. В промпте ссылаться: «человек с приложенного изображения»
4. Менять в описании только сцену и ракурс, внешность не переописывать

Переописание внешности в каждом промпте даёт нового человека каждый раз.

## Тематика здоровья

- Не изображать приём препарата как лечение
- Не показывать медицинские процедуры и диагнозы
- Люди — обычные, без «до/после»
- Никаких белых халатов, если это не реальные специалисты бренда: имитация врача вводит в заблуждение

## Отрицания

Модель плохо работает с «не». Вместо «без текста на изображении» — описать, что **должно** быть: «чистый фон, свободный от надписей».

## Итерация

Менять **по одному параметру** за раз: сначала свет, потом композицию, потом стиль. Переписав промпт целиком, не поймёшь, что сработало.

Удачные промпты сохранять в `knowledge/` воркспейса — подбор стоит денег, переиспользование бесплатно.
