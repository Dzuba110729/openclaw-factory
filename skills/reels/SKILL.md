# Reels — короткое вертикальное видео

Формат решается в первые 3 секунды. Всё остальное — работа с теми, кто уже остался.

## Жёсткие вводные

- Смотрят **без звука** — текст на экране обязателен
- Смотрят **на ходу** — одна мысль на ролик
- Вертикаль **9:16**, важное — в центральной трети: сверху и снизу интерфейс
- Оптимум **30–60 секунд**, потолок 90

## Первые 3 секунды

Это весь ролик, если их не прошли. Что работает:

| Приём | Как выглядит |
|-------|--------------|
| Прямое утверждение | «Витамины могут не усваиваться вообще» |
| Вопрос-узнавание | «Просыпаетесь разбитым?» |
| Визуальный контраст | Действие в кадре с первого кадра |
| Обещание с цифрой | «Три причины. Первая неочевидна» |

Чего не делать: заставка, логотип, «привет, друзья», представление спикера. Всё это — отписка ещё до содержания.

## Структура ролика

```
0–3 сек    Хук. Текст на экране одновременно с речью
3–10 сек   Проблема. Узнавание
10–40 сек  Суть. 2–3 тезиса, по одному на 10 секунд
40–55 сек  Вывод
55–60 сек  Призыв. Один, конкретный
```

## Текст на экране

- Крупно, в центральной трети
- Одна строка — одна мысль, 4–7 слов
- Дублирует речь, а не дополняет: смотрят без звука
- Смена текста каждые 2–3 секунды — удерживает взгляд
- Контрастная подложка под текстом, иначе на светлом кадре не видно

## Сценарий: формат записи

```
[КАДР]   что в кадре
[ТЕКСТ]  что написано на экране
[РЕЧЬ]   что говорится
[СЕК]    хронометраж
```

Пишется до съёмки. Сценарий «по ходу разберёмся» даёт ролик, который переснимают.

## Ограничения в тематике здоровья

- Никаких обещаний результата и сроков
- Не показывать приём продукта как лечение
- Формулировки — по `knowledge/brand/voice-style.md`
- Отзыв клиента в ролике не является доказательством эффективности

## Проверка

- [ ] Первые 3 секунды работают без звука
- [ ] Одна мысль на ролик
- [ ] Текст читается на маленьком экране
- [ ] Ничего важного не под интерфейсом
- [ ] Призыв один
- [ ] Ролик понятен тому, кто не видел предыдущие
