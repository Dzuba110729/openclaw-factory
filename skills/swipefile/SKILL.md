# SwipeFile — библиотека приёмов

Свайпфайл — не папка со скриншотами. Это разобранные приёмы: что сработало, почему сработало и где это применимо у нас.

Скриншот без разбора бесполезен — через месяц непонятно, зачем его сохранили.

## Где хранится

В воркспейсе агента:

```
knowledge/swipefile/
  index.md          — список записей одной строкой, для быстрого поиска
  YYYY-MM-<слаг>.md — сама запись
```

Если каталога нет — создать при первой записи.

## Формат записи

```markdown
# <Короткое имя приёма>

**Источник:** площадка, автор, дата, ссылка
**Формат:** пост / карусель / видео / заголовок
**Зачем сохранил:** одна строка

## Что сделано
Фактическое описание: как устроен текст или визуал.

## Почему сработало
Механизм. Не «красиво», а какой именно приём удерживает внимание.

## Где применимо у нас
Конкретно: какая рубрика, какой продукт, какой тип поста.

## Чего не копировать
Что в этом приёме чужое — тон, тематика, уровень агрессии.
```

## Разбор чужого материала

Отвечай по порядку, коротко:

1. **Что зацепило в первые 2 секунды?** Первая строка, кадр, контраст
2. **Как удержано внимание дальше?** Обрывы, вопросы, структура
3. **Где здесь смысл, а где форма?** Форму копировать можно, смысл — нет
4. **Что бы я сделал иначе?** Это и есть адаптация под свой бренд
5. **Одна строка в `index.md`**

## Правила

- **Не копировать текст.** Копируется приём, а не формулировка. Скопированный текст заметят
- **Не тащить чужой тон.** Приём из агрессивного инфобиза в спокойном бренде выглядит фальшиво
- **Сохранять и провалы тоже.** Пост с плохим откликом объясняет больше удачного
- **Разбирать сразу.** Через неделю уже не вспомнишь, чем он зацепил

## Свои материалы

Свайпфайл ведётся и по собственным публикациям. Раз в месяц:

1. Взять статистику своих постов за период
2. Три лучших и три худших — разобрать по той же схеме
3. Найти повторяющийся признак
4. Вынести вывод в `learning/patterns.md` или `learning/anti-patterns.md` воркспейса

Это единственный способ отличить приём, который работает у нас, от приёма, который работает у кого-то другого.

## Использование при написании

Перед постом в незнакомом формате — посмотреть `index.md` по этому формату. Один-два разобранных примера перед глазами экономят черновик.
