# Carousel — слайды из текста

Карусель — это не нарезанный на куски пост. Это отдельный формат: каждый слайд должен читаться за секунду и вызывать желание листнуть.

## Рендер без зависимостей

Слайды собираются локально: HTML-шаблон → headless Chrome → PNG. Никаких платных API, никаких npm-пакетов.

```bash
node ~/.openclaw/skills/carousel/render/render.js slides.json ./out
```

Подробности и параметры — `references/rendering.md`.

## Правила слайдов

| Слайд | Задача | Лимит текста |
|-------|--------|--------------|
| 1-й (обложка) | Остановить прокрутку, пообещать пользу | 6–10 слов |
| 2-й | Обозначить проблему | до 15 слов |
| 3–6-й | По одной мысли на слайд | до 12 слов |
| Предпоследний | Вывод | до 15 слов |
| Последний | Призыв к действию | до 10 слов |

**Оптимум — 5–7 слайдов.** Больше десяти не долистывают.

## Жёсткие ограничения

- **Одна мысль на слайд.** Две мысли — два слайда
- **Шрифт крупнее, чем кажется.** Смотреть будут с телефона в руке на ходу
- **Единый шаблон.** Разный дизайн слайдов = набор картинок, а не карусель
- **Первый слайд не дублирует подпись к посту** — иначе нет причины листать
- **Ничего важного по краям.** Интерфейс площадки обрежет

## Порядок работы

1. Взять готовый текст или написать через скилл `copywriting`
2. Выделить ядро: один тезис
3. Разложить на слайды — по одной мысли
4. Сократить каждый слайд до лимита. Это самый важный шаг: текст, влезающий в слайд, всегда короче, чем кажется
5. Собрать `slides.json`
6. Отрендерить, посмотреть глазами
7. Написать подпись к карусели (400–800 знаков) через скилл `content-repurposer`

## Проверка перед отправкой

- [ ] Первый слайд работает сам по себе
- [ ] На каждом слайде одна мысль
- [ ] Текст читается с телефона не щурясь
- [ ] Последний слайд говорит, что делать
- [ ] Нумерация слайдов не сбита
- [ ] Ничего важного не ушло под обрез
