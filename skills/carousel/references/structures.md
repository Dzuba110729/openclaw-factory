# Структуры каруселей

## 1. Разбор механизма (основной для научного контента)

```
1. Обложка   — вопрос: «Почему X не работает?»
2. Проблема  — знакомая ситуация читателя
3. Причина   — что происходит на самом деле
4. Цепочка   — A → B → C
5. Следствие — к чему это приводит
6. Решение   — что с этим делать
7. CTA       — следующий шаг
```

Самая сильная структура, когда есть что объяснить. Держит долистывание за счёт цепочки.

## 2. Ошибки

```
1. Обложка   — «N ошибок, из-за которых...»
2–6. Ошибка  — по одной на слайд: в чём ошибка + чем заменить
7. CTA
```

Каждый слайд самодостаточен — такие карусели чаще сохраняют.

## 3. Было / стало

```
1. Обложка   — обещание перемены
2. Было      — исходная точка, честно
3. Что мешало
4. Что изменили
5. Стало     — конкретно, без обещаний повторяемости
6. Вывод
7. CTA
```

В тематике здоровья — осторожно: результат одного человека не является обещанием другим.

## 4. Разбор термина

```
1. Обложка   — «X простыми словами»
2. Что это НЕ
3. Что это
4. Как работает
5. Кому нужно
6. Кому не нужно     ← даёт доверие
7. CTA
```

Слайд «кому не нужно» повышает доверие сильнее любых аргументов «за».

## 5. Чек-лист

```
1. Обложка   — «Проверьте себя: N признаков»
2–6. Признак — по одному на слайд
7. Итог      — что делать, если совпало 3+
```

Хорошо сохраняется, легко пересылается.

## 6. Сравнение

```
1. Обложка   — «A или B?»
2. Что такое A
3. Что такое B
4. В чём разница по существу
5. Когда подходит A
6. Когда подходит B
7. CTA
```

Работает на аудиторию, которая уже выбирает.

## Как выбрать структуру

| Задача | Структура |
|--------|-----------|
| Объяснить, почему продукт работает | Разбор механизма |
| Снять недоверие | Разбор термина, Сравнение |
| Собрать сохранения | Ошибки, Чек-лист |
| Показать опыт | Было / стало |
| Помочь выбрать | Сравнение |

## Общее правило финала

Последний слайд — **одно** действие. Не три варианта, не «подписывайтесь, ставьте лайк и пишите в комментариях». Одно.
