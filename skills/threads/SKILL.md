# Threads — цепочки постов

Тред — это одна мысль, разложенная на шаги так, что каждый шаг тянет к следующему. Не нарезанная статья.

> **Примечание.** Основные площадки бренда — Telegram и ВКонтакте. Здесь приём описан универсально: он одинаково работает для Threads, X и для серии связанных постов в Telegram.

## Каркас

```
1. Крючок      — тезис или обещание. Читается отдельно от всего
2. Контекст    — почему это важно сейчас
3–7. Шаги      — по одной мысли, каждый заканчивается зацепкой
8. Вывод       — что из этого следует
9. Призыв      — одно действие
```

Оптимум — 5–9 частей. Длиннее дочитывают единицы.

## Первый пост решает всё

Остальные увидят только те, кто зацепился за первый. Поэтому:

- Он должен быть понятен **без** остальных
- В нём — обещание конкретной пользы
- Без «тред 🧵», «сейчас расскажу», «погнали»
- Цифра работает: «Разобрал 5 причин. Пятая неочевидна»

## Связки между частями

Каждая часть заканчивается тем, что требует продолжения:

- «Но есть нюанс.»
- «Здесь большинство ошибается.»
- «Дальше интереснее.»
- Незакрытый вопрос

Без связок тред рассыпается на отдельные заметки.

## Правила частей

- Одна мысль на часть, без исключений
- Часть читается сама по себе — люди заходят с середины
- Не нумеровать «1/9»: нумерация показывает длину и отпугивает. Нумеровать по смыслу, если нужно
- Не переносить предложение через границу частей

## Для Telegram

Серия постов в канале — тот же приём, но с поправками:

- Части выходят **не подряд**, а по одной в день или через день
- В конце части — когда выйдет следующая, и этот срок соблюдать
- Первую часть закрепить на время выхода серии
- В каждой следующей — одна строка напоминания, о чём была предыдущая

## Проверка

- [ ] Первая часть работает как самостоятельный пост
- [ ] В каждой части ровно одна мысль
- [ ] Между частями есть зацепки
- [ ] Последняя даёт вывод, а не обрывается
- [ ] Призыв один
