# Чек-лист вычитки

Порядок важен: правка стиля до правки смысла — потерянное время, потому что часть текста всё равно уйдёт.

## Шаг 1. Смысл (5 минут)

- [ ] Тема текста формулируется одной фразой
- [ ] Каждый абзац работает на эту фразу
- [ ] Есть вывод, читатель понял, что делать
- [ ] Нет двух тем в одном тексте — если есть, режем на два

## Шаг 2. Структура

- [ ] Первая строка самостоятельна и цепляет
- [ ] Порядок блоков логичен: проблема раньше решения, механизм раньше вывода
- [ ] Нет провалов — мест, где мысль перескакивает
- [ ] Абзацы не длиннее 4 строк
- [ ] Призыв один, конкретный, в конце

## Шаг 3. Шум

- [ ] Прогнать по `stop-words.md`
- [ ] Убрать канцелярит и отглагольные существительные
- [ ] Найти повторы слов в соседних предложениях
- [ ] Сократить текст на 30–50%

## Шаг 4. Факты

- [ ] Каждое утверждение о продукте подкреплено
- [ ] Нет «лечит», «вылечивает», «гарантируем результат», «заменяет лекарства»
- [ ] Цифры, названия, дозировки проверены
- [ ] Ссылки открываются
- [ ] Текст не протух: даты, сроки, акции, «до конца месяца» — актуальны **на день публикации**, а не на день написания

## Шаг 5. Ритм

- [ ] Прочитать вслух целиком
- [ ] Длина предложений разная
- [ ] Нет мест, где спотыкаешься
- [ ] Нет трёх одинаковых начал абзацев подряд

## Шаг 6. Оформление

- [ ] Эмодзи не больше 3–5, работают как маркеры
- [ ] Жирным выделено 1–2 места
- [ ] Нет КАПСА и лишних восклицательных знаков
- [ ] Пробелы и переносы не съехали
- [ ] Проверена типографика: тире вместо дефиса, кавычки-ёлочки

## Отдельно для залежавшегося текста

Если текст написан больше 3 дней назад, перед отправкой на согласование:

- [ ] Все временные привязки пересчитаны («через неделю» — от какой даты?)
- [ ] Упоминания сезона, месяца, праздника всё ещё уместны
- [ ] Акция или срок не истекли
- [ ] Инфоповод не устарел
