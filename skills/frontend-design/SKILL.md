# Frontend Design — Думай сначала, потом кодируй

Сначала дизайн-мышление. Потом код. Никаких шаблонов и «стандартных» вариантов.

## Шаг 1: Осмыслить задачу

Перед тем как писать код — ответь себе:
- **Цель:** Что должен почувствовать пользователь? Что он сделает?
- **Тональность:** Выбери одну крайность: брутально-минималистичный / максималистски-яркий / ретро-футуристичный / органика / люксовый / игровой / редакционный / индустриальный
- **Запоминаемость:** Что одно человек запомнит с первого взгляда?
- **Бренд {{BRAND}}:** палитра, шрифты и характер из скилла `brand-kit` — применить или осознанно нарушить

## Шаг 2: Дизайн-принципы кода

**Типографика:**
- Неожиданные, характерные шрифты — не Arial, не Roboto, не Inter
- Пара: выразительный заголовочный + читаемый текстовый
- Для {{BRAND}}: пара шрифтов из `brand-kit`

**Цвет:**
- Доминирующий цвет + 1-2 острых акцента, не равномерная раскладка
- Палитра {{BRAND}}: из `brand-kit`
- CSS переменные для консистентности

**Движение:**
- CSS-анимации для загрузки, ховер-состояний
- Staggered reveals (animation-delay) на странице
- Один хорошо срежиссированный эффект лучше десяти мелких

**Композиция:**
- Асимметрия, перекрытия, диагональные линии
- Щедрый негативный пробел ИЛИ плотная насыщенность — выбрать одно
- Grid-breaking элементы

**Фоны и детали:**
- Градиентные сетки, текстуры, геометрические паттерны
- Не сплошной белый/серый фон
- Тень, зернистость, декоративные рамки

## Запрещено

❌ Фиолетовые градиенты на белом — визитка «дешёвого AI»
❌ Space Grotesk, Inter, Roboto как основной шрифт
❌ Предсказуемые карточки с тенью и скругленными углами (по умолчанию)
❌ Bootstrap/Tailwind-шаблонность без осмысления

## Стек

- Чистый HTML+CSS+JS (приоритет) или React
- Google Fonts для шрифтов
- CSS Grid / Flexbox для раскладки
- CSS Custom Properties для темы
