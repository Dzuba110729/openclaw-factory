# Canvas Design — Философия сначала, визуал потом

Два шага: философия → воплощение.

## Шаг 1: Создать визуальную философию

Дай направлению НАЗВАНИЕ (1-2 слова): "Зелёная Сила" / "Чистота Природы" / "Биохакерская Точность"

Опиши философию через 4 аспекта:
1. **Пространство и форма** — как элементы занимают поле
2. **Цвет и материал** — палитра, текстуры, ощущение
3. **Ритм и масштаб** — крупное vs мелкое, плотность
4. **Иерархия** — что главное, что второстепенное

## Шаг 2: Воплотить на холсте

Создаёт HTML-файл с точными размерами → рендерю в PNG через Playwright:

```bash
# Рендер HTML → PNG (1080×1080 для поста ВК/Инст)
node -e "
const { chromium } = require('playwright');
(async () => {
  const browser = await chromium.launch();
  const page = await browser.newPage();
  await page.setViewportSize({ width: 1080, height: 1080 });
  await page.goto('file:///путь/к/design.html');
  await page.screenshot({ path: 'output.png', fullPage: false });
  await browser.close();
})();
"

```

## Форматы

| Формат | Размер | Применение |
|--------|--------|-----------|
| Пост ВК/Инст (квадрат) | 1080×1080 | Основные посты |
| Пост ВК (горизонталь) | 1200×630 | Анонсы, обложки |
| Сторис | 1080×1920 | Instagram Stories |
| YouTube превью | 1280×720 | Обложка видео |
| Баннер сайта | 1920×600 | Шапка сайта |

## Правила визуала (не нарушать)

- **90% визуал, 10% текст** — дизайн говорит, не слова
- **Mastercraft уровень** — будто делал профи часами, не минутами
- Избегать: стоковые паттерны, градиент-кружочки, Generic Sans
- Цвета бренда: из скилла `brand-kit`
