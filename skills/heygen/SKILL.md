# HeyGen — AI-аватары

Этот скилл готовит **материал** для HeyGen: текст под озвучку и промпты для оживления фото. Сама генерация делается в интерфейсе HeyGen под твоим аккаунтом — API-ключа в системе нет и он не требуется.

## Правила текста для озвучки

Синтез читает буквально. Что ломает озвучку:

| ❌ Не писать | ✅ Писать |
|--------------|-----------|
| «500 мг» | «пятьсот миллиграммов» |
| «ЖКТ» | «жэ-ка-тэ» или «желудочно-кишечный тракт» |
| «т.д.», «т.п.» | «и так далее» |
| «10-15 минут» | «от десяти до пятнадцати минут» |
| «№1» | «номер один» |
| «~2 недели» | «около двух недель» |
| «BRAND» | «Бренд» — латиницу читает по буквам, пиши название кириллицей |
| Скобки с пояснением | Отдельное предложение |
| Тире как пауза | Точка |

## Длина и ритм

- Предложение — **до 20 слов**. Длиннее теряется интонация
- Одна мысль — одно предложение
- Абзац — 2–4 предложения, между ними синтез делает паузу
- Общая длина ролика — до 10 минут, но лучше 1–3

## Интонация

Синтез не понимает иронии и подтекста. Поэтому:

- Писать прямо, без намёков
- Риторические вопросы — максимум один, иначе звучит навязчиво
- Восклицательные знаки — не больше одного на ролик
- Многоточия убирать: пауза получается неестественной

## Структура скрипта

```
0–10 сек   Кто говорит и о чём. Коротко
10–20 сек  Зачем это слушать
Основная   2–3 тезиса, каждый отдельным абзацем
Финал      Вывод и одно действие
```

Текст писать через скиллы `copywriting` и `editing`, затем адаптировать по правилам выше.

## Оживление фотографии

Промпт описывает **только движение**, не внешность:

```
Лёгкий поворот головы вправо, естественное моргание,
едва заметное движение плеч при дыхании, камера статична
```

Правила:

- Одно-два движения, не больше
- 5–10 секунд на промпт
- Камера статична — движение камеры плюс движение лица даёт артефакты
- Исходное фото: анфас или лёгкие три четверти, лицо крупно, резкое, ровный свет

Фото для аватара можно сгенерировать скиллом `nano-banana`.

## Склейка

Длинный ролик собирается из отрезков по 5–10 секунд:

1. Отрезки в одном разрешении и с одним фоном
2. Склейка — скилл `video-editor`
3. Стыки прятать сменой плана или перебивкой
4. Субтитры вшивать после склейки

## Ограничения

- **Не выдавать аватар за реального человека.** Если это синтез — либо очевидно по контексту, либо помечено
- **Не делать аватар в образе врача** — имитация медицинского специалиста вводит в заблуждение
- Лицо реального человека использовать только с его разрешения
- Медицинские утверждения — по тем же правилам, что в тексте: без «лечит» и обещаний результата

## Чек-лист перед генерацией

- [ ] Все числа и аббревиатуры прописаны словами
- [ ] Нет предложений длиннее 20 слов
- [ ] Латиница заменена транскрипцией
- [ ] Текст прочитан вслух — звучит естественно
- [ ] Скобки и многоточия убраны
- [ ] Понятно, что это синтезированный аватар
