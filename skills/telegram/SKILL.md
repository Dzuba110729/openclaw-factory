# Telegram — контент для канала

Telegram — площадка выбора, а не случайного показа. Подписчик уже согласился вас читать, но и отписывается одним движением.

## Что определяет успех поста

Три метрики, в порядке важности:

1. **Пересылки** — единственный органический канал роста
2. **Дочитывания** — видно по охвату относительно подписчиков
3. **Реакции** — быстрый сигнал, но самый поверхностный

Отсюда правило: в каждом посте должно быть **что переслать**. Один факт, цифра или формулировка, которую захочется показать другому.

## Первые три строки

В ленте видно около трёх строк до кнопки «Показать полностью». Это всё, что у вас есть.

- Строка 1 — хук, самостоятельный
- Строка 2 — развитие или обещание
- Строка 3 — обрыв на интересном

Не тратить эти строки на: приветствие, дату, название рубрики, дисклеймер.

## Частота и ритм

- 3 поста в неделю — рабочий минимум для живого канала
- Больше 2 постов в день — растёт отписка
- Между продуктовыми постами — минимум два непродуктовых
- Лучшее время определяется по своей статистике, а не по общим советам

## Серии

Серия из 2–3 постов держит внимание лучше одного длинного.

- В конце части — явный анонс следующей и когда она выйдет
- Обещанный срок соблюдать, иначе доверие к анонсам падает
- Первую часть закрепить на время выхода серии

## Прогрев

Последовательность постов, подводящая к предложению. Рабочая пропорция: **4 полезных поста на 1 продающий**.

```
1. Проблема — читатель узнаёт свою ситуацию
2. Механизм — почему так происходит
3. Ошибка — почему привычные решения не работают
4. Доказательство — исследование, документ, опыт
5. Предложение — что мы предлагаем и для кого
```

Продающий пост без первых четырёх работает вхолостую.

## Комментарии и реакции

- Отвечать на вопросы по существу, не дежурными фразами
- Возражения закрывать спокойно, без защитной реакции
- На агрессию — с достоинством, без ответной агрессии
- Вопросы по продукту, требующие персональной консультации, уводить в поддержку

## Перед публикацией

- [ ] Первая строка работает без остальных
- [ ] Есть что переслать
- [ ] Разметка не поехала (проверить предпросмотром)
- [ ] Ссылки открываются
- [ ] Текст не протух: даты, сроки, сезон — актуальны на день публикации
- [ ] Обложка не дублирует первую строку
