# Оформление и лимиты Telegram

## Разметка

Telegram поддерживает два режима — HTML и MarkdownV2. Для постов через Bot API надёжнее HTML: в MarkdownV2 нужно экранировать полтора десятка символов, и любой пропущенный ломает отправку целиком.

| Оформление | HTML | Markdown |
|------------|------|----------|
| Жирный | `<b>текст</b>` | `*текст*` |
| Курсив | `<i>текст</i>` | `_текст_` |
| Подчёркнутый | `<u>текст</u>` | `__текст__` |
| Зачёркнутый | `<s>текст</s>` | `~текст~` |
| Моноширинный | `<code>текст</code>` | `` `текст` `` |
| Блок кода | `<pre>текст</pre>` | ` ```текст``` ` |
| Скрытый (спойлер) | `<tg-spoiler>текст</tg-spoiler>` | `\|\|текст\|\|` |
| Ссылка | `<a href="url">текст</a>` | `[текст](url)` |
| Цитата | `<blockquote>текст</blockquote>` | — |

В MarkdownV2 экранировать обратным слэшем: `_ * [ ] ( ) ~ ` > # + - = | { } . !`

## Лимиты

| Что | Лимит |
|-----|-------|
| Текст сообщения | 4096 знаков |
| Подпись к медиа | 1024 знака |
| Файл через Bot API | 50 МБ |
| Фото | 10 МБ |
| Медиагруппа | 10 файлов |
| Кнопок в ряду | 8 |
| Опрос: вариантов | 10 |

**Важно:** подпись к фото — всего 1024 знака. Пост длиннее придётся либо слать текстом без картинки, либо картинкой + отдельным сообщением.

## Приёмы оформления

**Спойлер** — для ответа на вопрос, заданный в начале поста. Читатель тапает сам, это микро-вовлечение.

**Цитата** (`blockquote`) — для выделения главного тезиса. Работает лучше жирного, если тезис длинный.

**Моноширинный** — для дозировок, составов, кодов. Удобно копировать в один тап.

**Эмодзи как маркеры списка** — вместо дефисов. Но один и тот же эмодзи на весь список, а не зоопарк.

## Чего избегать

- Больше 3–5 эмодзи на пост
- Жирным больше двух фрагментов — теряется акцент
- КАПС
- Двойные пустые строки — Telegram их схлопывает непредсказуемо
- Ссылка в первой строке — превью перекрывает хук

## Превью ссылок

Telegram разворачивает первую ссылку в тексте. Если превью не нужно:

- Bot API: параметр `disable_web_page_preview: true`
- В интерфейсе: убрать превью перед отправкой

Если превью нужно и оно важнее текста — ссылку ставить в начало, Telegram покажет карточку сверху.

## Отправка через OpenClaw

Файл или изображение владельцу — только через exec, теги `MEDIA:` с абсолютными путями заблокированы:

```bash
openclaw message send --channel telegram --account <агент> --target <id> --media <путь> --message "подпись"
```

Разрешённые каталоги для отправки: `/tmp/openclaw/` и `~/.openclaw/media/shared/`. Обычный `/tmp/файл.png` заблокирован.

Несколько файлов — по одной команде на файл.
