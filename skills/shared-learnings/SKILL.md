# Shared Learnings — общий свод выученного

Урок, который выучил один агент, не должен переоткрываться остальными восемью.

## Где лежит

```
~/.openclaw/media/shared/learnings/
  patterns.md        — что работает
  anti-patterns.md   — что не работает
  corrections.md     — правки владельца
```

Локальные, специфичные для одного агента, остаются у него в `learning/`. Сюда попадает только то, что применимо другим.

## Что попадает в общий свод

| Попадает | Не попадает |
|----------|-------------|
| Правило, применимое минимум двум агентам | Специфика одной площадки |
| Повторная правка владельца одного типа | Разовое замечание |
| Обнаруженное ограничение системы | Баг конкретной задачи |
| Формулировка, которая стабильно заходит | Удачный текст одного поста |

## Формат записи

```markdown
## <Правило одной строкой>

**Когда:** в какой ситуации применимо
**Почему:** что произошло, из-за чего вывод
**Кому:** каким агентам
**Дата:** YYYY-MM-DD
```

Без «почему» правило через месяц выглядит произволом, и его нарушат.

## Как пополнять

Повод записать:

1. Владелец поправил одно и то же **дважды**
2. Вскрылось ограничение системы, на которое потратили время
3. Приём стабильно сработал трижды
4. Ошибка, которую легко повторить другому агенту

Один раз — случайность, записывать рано. Дважды — уже правило.

## Как применять

- В начале работы над незнакомой задачей — заглянуть в `anti-patterns.md`
- Перед отправкой результата владельцу — сверить с `corrections.md`
- Не читать всё подряд каждый раз: искать по теме

## Гигиена

- Правило, которое перестало быть верным, — **помечать датой и причиной**, а не удалять. Иначе кто-нибудь выведет его заново
- Противоречащие правила — разбирать, а не копить оба
- Свод длиннее 100 строк — сворачивать: частные случаи объединять в общее правило
- Раз в квартал перечитывать: часть правил окажется устаревшей

## Связь с памятью агента

| Где | Что |
|-----|-----|
| `learning/` агента | локальное, только для него |
| `shared/learnings/` | общее, для всех |
| `MEMORY.md` агента | его собственные выводы и решения |

Дублировать одно и то же в трёх местах не надо. Общее — наверх, частное — вниз.
