# Video Editor — обработка видео

Инструмент — `ffmpeg`. Всё делается из командной строки, без редактора.

## Инструмент

`ffmpeg` установлен (9.0.1, `/opt/homebrew/bin/ffmpeg`), вместе с `ffprobe`. Проверка: `ffmpeg -version`.

## Частые операции

```bash
# обрезать по времени (с 5-й секунды, длительность 30 с)
ffmpeg -ss 5 -i in.mp4 -t 30 -c copy out.mp4

# склеить несколько файлов (одинаковый кодек)
printf "file '%s'\n" a.mp4 b.mp4 c.mp4 > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy out.mp4

# вертикаль 9:16 из горизонтали — обрезкой по центру
ffmpeg -i in.mp4 -vf "crop=ih*9/16:ih,scale=1080:1920" -c:a copy out.mp4

# сжать для отправки
ffmpeg -i in.mp4 -vcodec libx264 -crf 28 -preset slow out.mp4

# вытащить кадр
ffmpeg -ss 3 -i in.mp4 -frames:v 1 frame.png

# убрать звук
ffmpeg -i in.mp4 -an -c:v copy out.mp4

# нормализовать громкость
ffmpeg -i in.mp4 -af loudnorm -c:v copy out.mp4
```

`-c copy` не перекодирует — быстро и без потерь, но работает только когда кодек не меняется.

## Субтитры

Смотрят без звука, поэтому субтитры обязательны.

```bash
# вшить субтитры в картинку (hardsub)
ffmpeg -i in.mp4 -vf "subtitles=subs.srt:force_style='FontSize=18,PrimaryColour=&HFFFFFF&,OutlineColour=&H000000&,BorderStyle=3'" out.mp4

# отдельной дорожкой (можно выключить)
ffmpeg -i in.mp4 -i subs.srt -c copy -c:s mov_text out.mp4
```

Для соцсетей — только hardsub: отдельная дорожка там не показывается.

Формат `.srt`:

```
1
00:00:00,000 --> 00:00:02,500
Первая строка субтитров

2
00:00:02,500 --> 00:00:05,000
Вторая строка
```

Правила: 4–7 слов в строке, не больше двух строк одновременно, смена каждые 2–3 секунды.

## Форматы под площадки

| Площадка | Разрешение | Кодек | Примечание |
|----------|-----------|-------|-----------|
| Вертикальное видео | 1080×1920 | H.264 | важное в центральной трети |
| Лента | 1080×1350 | H.264 | |
| YouTube | 1920×1080 | H.264 | до 4K, если исходник позволяет |
| Telegram | до 1080p | H.264 | файл до 50 МБ через Bot API |

Звук везде — AAC, 128–192 kbps.

## Диагностика

```bash
ffprobe -v error -show_format -show_streams in.mp4   # что внутри файла
```

| Проблема | Причина |
|----------|---------|
| Склейка рассыпалась | у файлов разные кодеки — перекодировать, не `-c copy` |
| Видео не играет в Telegram | не H.264/AAC или слишком большой файл |
| Субтитры не видны | отдельная дорожка вместо hardsub |
| Звук рассинхронизировался | разная частота кадров у исходников |

## Порядок работы

1. Посмотреть исходник через `ffprobe`
2. Сначала резать и склеивать с `-c copy` — быстро
3. Перекодировать **один раз**, в конце
4. Субтитры вшивать последним шагом
5. Проверить результат глазами, на телефоне
